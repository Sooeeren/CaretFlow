# Keyboard shortcuts

Every command in CaretFlow is in a menu and in the command palette (`F1` or `Ctrl+Shift+P`).
`Shift+F1` lists all shortcuts inside the app. Any command can get a different shortcut, or none, in
**Preferences → Keyboard** (Help → Customize Shortcuts…). These are the defaults. Shortcuts marked
*(extension)* work once that extension is installed (Preferences → Extensions).

## In the editor

| Where | Keys |
| --- | --- |
| Links | `Ctrl+Click` opens them (a plain click in read-only mode) |
| Empty line | `/` opens the block menu |
| Tables | `Enter` in the last row adds a row |
| Right after an AutoCorrect fix | `Backspace` undoes it |
| Spelling review panel | number keys pick a suggestion, `Enter` applies the first |
| Vim mode | `:w`, `:q`, `:wq`, `:e`, `:pre` (back to the rendered view), `Ctrl+A` / `Ctrl+X` on numbers |
